UNICORN JABU
------------

- LEGENDA:

F = Avanti / Forward
B = Indietro / Backward
U = Su / Up
D = Giù / Down
x = Pugno Debole / Weak Punch
y = Pugno Medio / Medium Punch
z = Pugno Forte / Strong Punch
a = Calcio Debole / Weak Kick
b = Calcio Medio / Medium Kick
c = Calcio Forte / Strong Kick
s = Provocazione / Taunt

- SUPER MOVES:

Invocazione dell'Unicorno / Unicorn Summon = B, DB, D, DF, F, a (Power 1000)
Fulmini dell'Unicorno / Unicorn Lightnings = B, DB, D, DF, F, x (Power 1000)
Incornata dell'Unicorno / Unicorn Horn = B, DB, D, DF, F, y (Power 2000)
Criniera dell'Unicorno / Unicorn Gallop = B, DB, D, DF, F, z (Power 3000)

- SPECIAL MOVES:

Doppio Calcio dell'Unicorno / Unicorn Double Kick = D, DF, F, x/y/z
Carica dell'Unicorno / Unicorn Combo Kick = D, DB, B, x/y/z
Mille Zoccoli dell'Unicorno / Thousands Unicorn Hoofs = D, DF, F, a/b/c
Mille Zoccoli dell'Unicorno Aerei / Thousands Unicorn Aerial Hoofs = U, D, DF, F, a/b/c
Trappola dell'Unicorno / Unicorn Trap = D, DB, B, a/b/c
Calcio Volante dell'Unicorno / Unicorn Flying Kick = U, D, DB, B, a/b/c
Contrattacco dell'Unicorno / Unicorn Counterattack = x + y
Carica Cosmo / Cosmo Charge = c + z

PER VISUALIZZARE LA LISTA DELLE MOSSE DURANTE IL GIOCO, PREMERE DUE VOLTE E VELOCEMENTE IL TASTO START (s) / TO VIEW THE MOVELIST DURING THE GAME, PRESS TWICE AND QUICKLY THE START KEY (s)
