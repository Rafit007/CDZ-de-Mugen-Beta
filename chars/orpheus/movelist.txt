LYRA ORPHEUS
------------

- LEGENDA:

F = Avanti / Forward
B = Indietro / Backward
U = Su / Up
D = Giù / Down
x = Pugno Debole / Weak Punch
y = Pugno Medio / Medium Punch
z = Pugno Forte / Strong Punch
a = Calcio Debole / Weak Kick
b = Calcio Medio / Medium Kick
c = Calcio Forte / Strong Kick
s = Provocazione / Taunt

- SUPER MOVES:

Melodia della Notte / Stringer Nocturne = B, DB, B, DF, F, x (Power 1000) 
Sinfonia dell'Eterna Quiete / Death Trip Serenade = B, DB, D, DF, F, y (Power 2000)
Requiem Finale / Stringer Fine = B, DB, D, DF, F, z  (Power 3000)

- SPECIAL MOVES:

Onda d'urto musicale / Music Wave = D, DF, F, x/y/z
Pugno della Lira / Lyra-Punch = D, DB, B, x/y/z
Ginocchiate / Knee Hits = D, DF, F, a/b/c
Calci rapidi / Flash Kicks = D, DB, B, a/b/c
Calcio Uppercut / Uppercut Kick = F, D, DF, a/b/c
Tocco Melodico / Melodic Touch = x + y
Presa Musicale / Music Throw = F + z
Carica Cosmo / Cosmo Charge = c + z

PER VISUALIZZARE LA LISTA DELLE MOSSE DURANTE IL GIOCO, PREMERE DUE VOLTE E VELOCEMENTE IL TASTO START (s) / TO VIEW THE MOVELIST DURING THE GAME, PRESS TWICE AND QUICKLY THE START KEY (s)
