CYGNUS HYOGA
------------

- LEGENDA:

F = Avanti / Forward
B = Indietro / Backward
U = Su / Up
D = Giù / Down
x = Pugno Debole / Weak Punch
y = Pugno Medio / Medium Punch
x = Pugno Forte / Strong Punch
a = Calcio Debole / Weak Kick
b = Calcio Medio / Medium Kick
c = Calcio Forte / Strong Kick
s = Provocazione / Taunt

- SUPER MOVES:

Polvere di Diamanti / Diamond Dust = B, DB, D, DF, F, x (Power 1000)
Aurora del Nord / Aurora Thunder Attack V1 = B, DB, D, DF, F, y (Power 2000)
Vortice Fulminante dell'Aurora / Aurora Thunder Attack V2 = B, DB, D, DF, F, z (Power 2000)
Sacro Aquarius / Aurora Execution = B, DB, D, DF, F, a (Power 3000)
Polvere di Diamanti senza Armatura / Diamond Dust without Cloth = B, DB, D, DF, F, b (Power 3000, Fatality Move)
Sacro Aquarius senza Armatura / Aurora Execution without Cloth = B, DB, D, DF, F, c (Power 3000, Desperate Move)
Settimo Senso / Seventh Sense = a + x (Power 3000, Desperate Move)
Sacro Aquarius Settimo Senso / Aurora Execution Seventh Sense = B, DB, D, DF, F, a (durante animazione 7° senso/during 7° sense animation)

- SPECIAL MOVES:

Tifone di Gelo Debole / Weak Kolodny Smerch = D, DF, F, x
Tifone di Gelo Forte / Strong Kolodny Smerch = D, DF, F, y
Congelamento delle Gambe / Leg Freeze = D, DF, F, z
Mini-Polvere di Diamanti / Mini-Diamond Dust = D, DF, F, a/b/c
Calcio del Cigno / Cygnus Kick = U, D, DF, F, a/b/c
Anelli di Ghiaccio / Koliso = D, DB, B, x/y/z
Volo del Cigno / Cygnus Flight = U, D, DB, B, a/b/c
Furia del Cigno / Cygnus Fury = F + z (Da vicino / From close distance)
Carica Cosmo / Cosmo Charge = c + z

PER VISUALIZZARE LA LISTA DELLE MOSSE DURANTE IL GIOCO, PREMERE DUE VOLTE E VELOCEMENTE IL TASTO START (s) / TO VIEW THE MOVELIST DURING THE GAME, PRESS TWICE AND QUICKLY THE START KEY (s)
