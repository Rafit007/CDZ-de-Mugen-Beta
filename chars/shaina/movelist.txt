OPHIUCHUS SHAINA
----------------

- LEGENDA:

F = Avanti / Forward
B = Indietro / Backward
U = Su / Up
D = Giù / Down
x = Pugno Debole / Weak Punch
y = Pugno Medio / Medium Punch
z = Pugno Forte / Strong Punch
a = Calcio Debole / Weak Kick
b = Calcio Medio / Medium Kick
c = Calcio Forte / Strong Kick
s = Provocazione / Taunt

- SUPER MOVES:

Artigli del Cobra LV1 / Thunder Claw LV1 = B, DB, D, DF, F, x (Power 1000)
Artigli del Cobra LV2 / Thunder Claw LV2 = B, DB, D, DF, F, y (Power 2000)
Cobra Incantatore / Thunder Claw LV3 = B, DB, D, DF, F, z (Power 3000)
Cobra Strangolante / Thunder Claw LV4 = B, DB, D, DF, F, a/b/c (Power 3000, Fatality Move)

- SPECIAL MOVES:

Gancio del Cobra / Cobra Uppercut = D, DF, F, x/y/z
Gancio Aereo del Cobra / Cobra Air Uppercut = U, D, DF, F, x/y/z
Pugno del Cobra / Cobra Punch = D, DB, B, x/y/z
Assalto del Cobra / Cobra Assault = D, DF, F, a/b/c
Calcio Aereo del Cobra / Cobra Air Kick = U, D, DF, F, a/b/c
Calcio Combo del Cobra / Cobra Combo Kick = D, DB, B, a/b/c
Calcio Rotante del Cobra / Cobra Axe Kick = D, DF, F, D, a/b/c
Scivolata / Slide = F/B + a + b
Scatto / Twitch = b + c
Graffi al Collo / Neck Scratches = y + z
Carica Cosmo / Cosmo Charge = c + z
Presa 1 / Throw 1 = F + z 
Presa 2 / Throw 2 = F + c
Presa Rotante Aerea / Aerial Rotating Throw) = c + z

PER VISUALIZZARE LA LISTA DELLE MOSSE DURANTE IL GIOCO, PREMERE DUE VOLTE E VELOCEMENTE IL TASTO START (s) / TO VIEW THE MOVELIST DURING THE GAME, PRESS TWICE AND QUICKLY THE START KEY (s)
