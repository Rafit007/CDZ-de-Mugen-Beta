KIKI
----

- LEGENDA:

F = Avanti / Forward
B = Indietro / Backward
U = Su / Up
D = Giù / Down
x = Pugno Debole / Weak Punch
y = Pugno Medio / Medium Punch
z = Pugno Forte / Strong Punch
a = Calcio Debole / Weak Kick
b = Calcio Medio / Medium Kick
c = Calcio Forte / Strong Kick
s = Provocazione / Taunt

- SUPER MOVES:

Raffica di Pietre / Stones Burst = B, DB, D, DF, F, x (Power 1000)
Telecinesi / Telekinesis = B, DB, D, DF, F, y (Power 2000)
Pioggia di Rocce / Rocks Rain = B, DB, D, DF, F, z (Power 3000)

- SPECIAL MOVES:

Bolide / Fireball = D, DF, F, x/y
Triplo Bolide / Triple Fireball = D, DF, F, z
Gomitata Fulminea / Elbow Dash = D, DB, B, x/y/z
Combo / Combo = D, DF, F, a/b/c
Calcio Volante / Flying Kick = U, D, DF, F, a/b/c
Teletrasporto / Teleport = b + c  (usa i comandi U, D, F e B per decidere dove riapparire\use the commands U, D, F and B to choose where re-appear)
Carica Cosmo / Cosmo Charge = c + z

PER VISUALIZZARE LA LISTA DELLE MOSSE DURANTE IL GIOCO, PREMERE DUE VOLTE E VELOCEMENTE IL TASTO START (s) / TO VIEW THE MOVELIST DURING THE GAME, PRESS TWICE AND QUICKLY THE START KEY (s)
