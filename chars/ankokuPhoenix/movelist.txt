ANKOKU PHOENIX
--------------

- LEGENDA:

F = Avanti / Forward
B = Indietro / Backward
U = Su / Up
D = Giù / Down
x = Pugno Debole / Weak Punch
y = Pugno Medio / Medium Punch
z = Pugno Forte / Strong Punch
a = Calcio Debole / Weak Kick
b = Calcio Medio / Medium Kick
c = Calcio Forte / Strong Kick
s = Provocazione / Taunt

Volo della Fenice Nera / Black Phoenix Flight = B, DB, D, DF, F, y (Power 2000)
Fantasma Diabolico Nero / Ankoku Houou GenMaKen = B, DB, D, DF, F, z (Power 3000)
