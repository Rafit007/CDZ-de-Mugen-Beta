CASSIOS
-------

- LEGENDA:

F = Avanti / Forward
B = Indietro / Backward
U = Su / Up
D = Giù / Down
x = Pugno Debole / Weak Punch
y = Pugno Medio / Medium Punch
z = Pugno Forte / Strong Punch
a = Calcio Debole / Weak Kick
b = Calcio Medio / Medium Kick
c = Calcio Forte / Strong Kick
s = Provocazione / Taunt

- SUPER MOVES:

Taglio dell'orecchio / Ear cutter = B, DB, D, DF, F, x (Power 1000) *Massimo 2 volte / Max 2 times
Super spallata / Super shoulder block = B, DB, D, DF, F, y  (Power 2000)
Pugno devastante / Devastating Punch = B, DB, D, DF, F, z (Power 2000)
Calcio devastante / Devastating Kick = B, DB, D, DF, F, a/b (Power 3000)
Abbraccio mortale / Deadly Hug = B, DB, D, DF, F, c (Power 3000, Desperate Move)

- SPECIAL MOVES:

Tripla spallata / Triple shoulder block = D, DF, F, x/y/z
Proiezione / Projection = D, DB, B, x/y/z 
Super Calcio Medio / Super Medium Kick = D, DF, F a/b
Super Calcio Forte / Super Strong Kick = D, DF, F, c
Calcio Terremotante / Earthquaking Kick = D, DB, B, a/b/c
Barriera di muscoli / Muscles barrier = y + z
Presa sanguinaria / Bloody Hold = F + z
Carica Cosmo / Cosmo Charge = c + z
Schivata / Dodge = a + b

PER VISUALIZZARE LA LISTA DELLE MOSSE DURANTE IL GIOCO, PREMERE DUE VOLTE E VELOCEMENTE IL TASTO START (s) / TO VIEW THE MOVELIST DURING THE GAME, PRESS TWICE AND QUICKLY THE START KEY (s)
