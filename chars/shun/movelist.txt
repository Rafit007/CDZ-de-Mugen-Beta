ANDROMEDA SHUN
--------------

- LEGENDA:

F = Avanti / Forward
B = Indietro / Backward
U = Su / Up
D = Giù / Down
x = Pugno Debole / Weak Punch
y = Pugno Medio / Medium Punch
z = Pugno Forte / Strong Punch
a = Calcio Debole / Weak Kick
b = Calcio Medio / Medium Kick
c = Calcio Forte / Strong Kick
s = Provocazione / Taunt

- SUPER MOVES:

Onde del Tuono / Thunder Wave = B, DB, D, DF, F, x (Power 1000)
Catena di Andromeda V1 / Nebula Chain V1 = B, DB, D, DF, F, y (Power 2000)
Catena di Andromeda V2 / Nebula Chain V2 = B, DB, D, DF, F, z (Power 3000)
Difesa Circolare V1 / Rolling Defense V1 = y + z (Power 1000)
Difesa Circolare V2 / Rolling Defense V2 = B, DB, D, DF, F, a (Power 1000)
Difesa Circolare V3 / Rolling Defense V3 = B, DB, D, DF, F, b (Power 2000)
Catena di Attacco / Rolling Defense + Thunder Wave = B, DB, D, DF, F, c (Power 3000)
Nebulosa di Andromeda / Nebula Storm = F, DF, D, DB, B, x/y/z (Power 3000, Fatality Move)
Soccorso Fraterno / Brotherly Aid = F, DF, D, DB, B, a/b/c (Power 3000, Desperate Move)
Settimo Senso / Seventh Sense = a + x (Power 3000, Desperate Move)
Catena di Andromeda Settimo Senso / Nebula Chain Seventh Sense = B, DB, D, DF, F, z (Durante animazione 7° senso / During 7° sense animation)

- SPECIAL MOVES:

Catena / Chain Attack = D, DF, F, x/y/z
Catena Aerea / Aerial Chain Attack = U, D, DF, F, x/y/z
Spirale di Andromeda / Nebula Spires = D, DB, B, x/y/z
Calcio della Nebulosa / Nebula Kick = D, DF, F, a/b/c
Calcio della Nebulosa Aereo / Aerial Nebula Kick = U, D, DF, F, a/b/c
Flusso della Nebulosa / Nebula Stream = D, DB, B, a/b/c
Scossa della Catena / Chain Electric Shock = x + y (Da vicino / From close distance)
Carica Cosmo / Cosmo Charge = c + z

PER VISUALIZZARE LA LISTA DELLE MOSSE DURANTE IL GIOCO, PREMERE DUE VOLTE E VELOCEMENTE IL TASTO START (s) / TO VIEW THE MOVELIST DURING THE GAME, PRESS TWICE AND QUICKLY THE START KEY (s)
