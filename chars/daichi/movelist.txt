VULPECULA DAICHI
----------------

- LEGENDA:

F = Avanti / Forward
B = Indietro / Backward
U = Su / Up
D = Giù / Down
x = Pugno Debole / Weak Punch
y = Pugno Medio / Medium Punch
z = Pugno Forte / Strong Punch
a = Calcio Debole / Weak Kick
b = Calcio Medio / Medium Kick
c = Calcio Forte / Strong Kick
s = Provocazione / Taunt
~30$ = Tieni premuto per mezzo secondo / Keep pressed for half second

- SUPER MOVES:

Cannonata della Volpetta / Fox Cannon = B, DB, D, DF, F, x (Power 1000)
Pugno Bomba / Bomb Punch = B, DB, D, DF, F, y (Power 2000)
Uragano d'Acciaio / Steel Hurricane = B, DB, D, DF, F, z (Power 3000)

- SPECIAL MOVES:

Combo Karate / Karate Combo = ~30$B, F, x/y/z
Pugno Flash / Flash Punch = D, DF, F, x/y/z
Pugno d'Acciaio / Steel Punch = D, DB, B, x/y/z
Armatura Meccanica / Mechanical Armour = D, DF, F, a/b/c
Terremoto della Volpetta / Hand Quake = x + y
Carica Cosmo / Cosmo Charge = c + z

PER VISUALIZZARE LA LISTA DELLE MOSSE DURANTE IL GIOCO, PREMERE DUE VOLTE E VELOCEMENTE IL TASTO START (s) / TO VIEW THE MOVELIST DURING THE GAME, PRESS TWICE AND QUICKLY THE START KEY (s)
