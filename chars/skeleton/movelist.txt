JAMIR SKELETON
--------------

- LEGENDA:

F = Avanti / Forward
B = Indietro / Backward
U = Su / Up
D = Giù / Down
x = Pugno Debole / Weak Punch
y = Pugno Medio / Medium Punch
z = Pugno Forte / Strong Punch
a = Calcio Debole / Weak Kick
b = Calcio Medio / Medium Kick
c = Calcio Forte / Strong Kick
s = Provocazione / Taunt

- SUPER MOVES:

1000 Pugni LV1 / 1000 Punches Lv1 = B, DB, D, DF, F, x (Power 1000)
1000 Calci LV1 / 1000 Kicks Lv1 = B, DB, D, DF, F, a (Power 1000)
1000 Pugni LV2 / 1000 Punches Lv2 = B, DB, D, DF, F, y (Power 2000)
1000 Calci LV2 / 1000 Kicks Lv2 = B, DB, D, DF, F, b (Power 2000)
Multi Costola Roteante / Multi Rotating Rib = B, DB, D, DF, F, z (Power 3000)
Super Combo con Teletrasporto / Super Combo With Teleport = B, DB, D, DF, F, c + F/B (per decidere dove apparire / to decide where to appear) (Power 3000)

- SPECIAL MOVES:

Costola Roteante / Rotating Rib = D, DF, F, x/y/z
100 Pugni / 100 Punches = D, DB, B, x/y
Costola Arpionatrice / Harpooning Rib = D, DB, B, z
100 Calci / 100 Kicks = D, DB, B, a/b/c
Calcio Volante / Flying Kick = D, DB, B, a/b/c (in aria / aerial)
Teletrasporto / Teleport = b + c + F/B (per decidere dove apparire / to decide where to appear)
Carica Cosmo / Cosmo Charge = c + z

PER VISUALIZZARE LA LISTA DELLE MOSSE DURANTE IL GIOCO, PREMERE DUE VOLTE E VELOCEMENTE IL TASTO START (s) / TO VIEW THE MOVELIST DURING THE GAME, PRESS TWICE AND QUICKLY THE START KEY (s)
